# SOC Stand

Стенд из 3 виртуальных машин для развёртывания и тестирования SOC-инструментов.

## О проекте

Учебный стенд для изучения безопасности контейнеров. Разворачивается одной командой `vagrant up`. Включает 3 VM с разными ролями: запуск контейнеров, хранение образов и сбор логов.

## Архитектура

| VM | IP | Роль | Ресурсы |
|---|---|---|---|
| **docker** | 192.168.56.10 | запуск контейнеров | 2 CPU, 2 GB |
| **docker_registry** | 192.168.56.11 | хранение образов | 2 CPU, 2 GB |
| **storage** | 192.168.56.12 | хранение логов | 2 CPU, 2 GB |

Все VM в одной подсети `192.168.56.0/24` (Host-Only).

## Стек технологий

| Технология | Назначение |
|---|---|
| **Vagrant** | управление VM |
| **VirtualBox** | провайдер виртуализации |
| **Docker** | контейнеризация |
| **Docker Registry** | приватный реестр образов |
| **NFS** | общая папка для логов |
| **SSL/TLS** | шифрование трафика |

## Требования

- **Vagrant** 2.4+
- **VirtualBox** 7.0+
- **Git**
- **RAM**: 8 GB
- **CPU**: 4 ядра
- **Диск**: 20 GB свободно

## Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/AndreyE888/soc-stand.git

# 2. Перейти в папку
cd soc-stand

# 3. Запустить стенд
vagrant up

# 4. Проверить статус
vagrant status
